Flip Streak 1.0.0 (build 4): gameplay recording

Recorded on the iOS Simulator (iPhone 17 Pro Max simulator, iOS 27.0), October 16, 2026, from a fresh install of the release build 1.0.0 (4). It is not a physical-device recording. The run was driven by an automated UI test that performs ordinary touch drags; no debug flags, seeded saves or altered game state were used. Silent, about 3 minutes.

Shown: launch, the four intro cards, levels 1-1 to 1-3 with real throws (including a miss and its coaching line), the Daily Shot, a Streak Run target, the Coin Purse, achievements, statistics and level select.
